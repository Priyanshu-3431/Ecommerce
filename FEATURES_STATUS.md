# ShopVerse Feature Status

This build keeps the normal customer storefront/account features and the responsive Admin panel. Seller and Delivery Partner roles, panels, registration APIs, management routes, demo accounts and related dashboards have been removed.

Customer features include authentication, profile, addresses, cart, wishlist, compare, orders, reorder, invoice data, reviews/Q&A, returns/replacements, support, notifications, wallet/loyalty, gift cards, alerts, recently viewed and recommendations.

Admin features include dashboard stats, products, orders, customers, returns/refunds, coupons, banners, categories, brands, inventory, support, analytics, flash sales, gift cards, audit/security controls and Cashfree-ready payment/refund operations.
